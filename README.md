# 🌍 地图投影可视化展示平台 (Map Projection Visualizer)

> **本项目是一个基于 Vue 3 + Three.js + D3.js 构建的地理数学交互式教学可视化平台。**  
> 核心目标是将抽象的地图投影过程，通过流畅的 3D 几何展开动画与 2D 平面地图实时互动展示出来。

---

## 🚀 1. 快速启动 (Quick Start)

**环境要求**：Node.js (建议 v16+ 环境)

```bash
# 1. 安装项目依赖
npm install

# 2. 启动本地开发服务器
npm run dev

# 3. 编译打包用于生产环境部署
npm run build
```

## ✨ 2. 重大版本更新与技术亮点 (Release Notes)

相较于最初仅有固定墨卡托投影的版本，当前系统已完成**全方位的 UI 极简重构与底层数学引擎的深度重写**，实现了真正的空间切向解算与等角/等面积实时切换。

### 🎨 2.1 极简仿 OpenCode 风格 UI 改造
*   去除了厚重的阴影、圆角和复杂的背景渐变，采用了纯白/浅灰的极简高级色彩搭配，使用极细的分割线划分模块。
*   全面移除了系统默认 Emoji 图标，引入了 `lucide-vue-next` 现代矢量图标库，提升界面的专业化。
*   顶部导航栏加入了**滚动毛玻璃渐隐（Scroll-Spy）**效果，在向下浏览时自动消隐背景减少干扰。
*   添加了科普文字面板，可以随着用户的操作实时联动切换对应的地理专业解说。

### 📐 2.2 核心突破：任意角度割投影 (Secant Projections)
*   **物理意义展示**：在左侧加入了“不变形线（标准纬线）”滑块，用户可直接拖动滑块使 3D 空间中的包裹圆柱/圆锥/平面**动态缩小并切入地球内部**。
*   **多维联动高亮**：无论是 3D 世界中的红色相交环线，还是底部 2D 地图上计算绘制的红色纬线，都会随着滑块的拖动做到毫秒级的实时重绘，彻底具象化“相割面处比例尺无变形”的抽象概念。

### 🔄 2.3 鼠标拖拽分离与空间斜轴投影 (Oblique Projections)
*   由于过去的联动会导致地球和几何体一起旋转，无法展示**斜轴投影**。
*   现已加入“鼠标拖拽模式”三态切换：
    1.  **视角旋转**：仅改变观察机位，参数不动。
    2.  **旋转地球**：几何体垂直固定，滚动地球，演示正常的原点平移。
    3.  **旋转切割面**：地球固定，旋转 3D 切割体。该模式不仅能在 3D 空间直观展示倾斜切入过程，下方的 D3 引擎会实时解算欧拉角 (Euler Angles)，同步渲染出极度扭曲的真实斜轴投影地图！

### 🌐 2.4 等角 (Conformal) 与 等面积 (Equal-Area) 实况对比
*   新增预设的一键切换 Tab，底层自动在对应的 D3 函数（如 `d3.geoMercator` 和 `d3.geoProjection(cylindricalEqualAreaRaw)`）之间无缝切换。
*   **3D 网格可视化 (Graticules)**：在 3D 空间中动态注入了灰色的经纬线网格。当切换等角时，高纬度网格被极度拉伸；切换等面积时，高纬度网格被压扁。无需展开地图，直接在球体表面就能对比出这两种经典变形。

### 🧭 2.5 现已支持三大投影族系
1.  **圆柱投影**：墨卡托 (等角) / 兰勃特圆柱 (等面积)
2.  **方位投影**：球极平面 (等角) / 兰勃特方位 (等面积)
3.  **圆锥投影**：兰勃特圆锥 (等角) / 阿尔伯斯圆锥 (等面积)

## 📂 3. 项目目录结构架构说明

为了保证高可维护性，项目严格遵守**“数据、UI、算法引擎”**相分离的架构模式。

```text
map-projection-visualizer/
├── public/                 # 静态资源目录（图标、离线 JSON 地图、赞赏码）
├── src/                    # 核心源代码目录 
│   ├── App.vue             # 【全局总控司令塔】负责整个 UI 架构、状态同步。
│   ├── main.js             # Vue 应用启动入口。
│   ├── components/         # UI 视图组件。 
│   │   ├── Map2D.vue       # D3.js 驱动的 2D 互动地图，包括下方的输入框与双向绑定面板。
│   │   └── Scene3D.vue     # Vue 包装层，负责将底层的 3D WebGL 画布安全嵌入网页。
│   └── core/               # 核心算法与渲染引擎（与前端框架完全解耦）
│       └── threeApp.js     # 整个项目的“灵魂核心”，包含地球生成、欧拉角坐标转换数学公式、WebGL 投影着色器(Shaders)、以及 GSAP 动画序列。
├── package.json            # 项目依赖清单
└── README.md               # 项目协作文档
```

## ⚡ 4. 核心机制：状态与双向联动通信

本项目的亮点在于 **3D 物理模型** 与 **2D 地图投影** 的实时互动。为防止数据冲突，系统维护唯一的全局状态，链路如下：

*   **唯一真理来源**：`App.vue` 中的 `globeRotation = ref({ lon: 0, lat: 0 })`。
*   **通信方向**：
    1. **3D 驱动 2D**：用户鼠标拖拽 3D 场景 -> `threeApp.js` 触发矩阵变换求出新的经纬度 -> 调用 `onRotationChange` 回调 -> `App.vue` 更新状态 -> `Map2D.vue` 收到 Props 变动 -> D3 旋转重绘平面图。
    2. **2D 驱动 3D**：用户拖动 `Map2D.vue` 下方滑块 -> `Map2D.vue` 发出 `emit` 事件 -> `App.vue` 更新数据 -> 直接调用 `setGlobeRotation()` API -> 3D 引擎使用四元数矩阵强制更新渲染。
